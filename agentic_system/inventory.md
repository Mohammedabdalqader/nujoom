## 7. What must be rebuilt, in the agreed order

1. **Identity and consent:** identity migration (profiles, profile_private, consents, user_settings, blocks), onboarding RPC, card codes, avatars (Storage bucket + RLS), config/flags from the database, auth (email code, magic link, Google, tester codes), session and journey routing, settings, player profile visibility, legal pages (web), web login.
2. **Pitches and booking:** pitches + media + favourites + ratings, busy ranges and slots, booking RPCs with the exclusion constraint and limits, match details, missing one, owner dashboard (web) with manual bookings.
3. **Invitations and guardian flow:** invite tokens and join (app + web page + deep link resume), friends (requests by card code, same age band, presence), notifications inbox + push devices + settings + worker push sender, guardian email invite (Edge Function), web guardian approval, replace contact, revoke.
4. **Check-in and match operations:** QR check-in (expo-camera), GPS signal, matches, events/timeline and score, recording device choice, match tools persistence (teams, gear, costs/payments).
5. **Recording and highlights:** R4a spike (stop and report), segments, uploads (R2 presigned), worker clip pipeline, clips, tags, likes, views, share pages, download rules.
6. **Ratings and progression:** votes, attribute ratings, endorsements, Elo, OVR, form, leaderboards, standings, player of the week, XP and stars ledgers, card image.
